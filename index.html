Installomator

The one installer script to rule them all.

A single, highly configurable installation script to seamlessly deploy standard software on Macs across your organization.

Learn More View Source on GitHub

MDM Agnostic

Whether you use Jamf Pro, Intune, FileWave, Addigy, Kandji, or Mosyle, Installomator integrates cleanly into your existing management framework as a standardized script.

Label Driven

Software is organized by "labels". Simply call the script with the desired label (e.g., googlechromepkg or slack) and Installomator handles the rest.

Always Up-to-Date

Instead of manually packaging browsers and common tools every week, Installomator reaches out to official vendor URLs to fetch the latest available version at runtime.

Trusted by the MacAdmins Community

Smart, Secure Deployments

Installomator doesn't just blindly download and install software. It runs a series of built-in checks to ensure updates are necessary, secure, and minimally disruptive to the end user.

  • Version Checking: Compares the currently installed version against the online vendor version.
  • Strict Security: Verifies the download is properly signed and notarized by Apple.
  • User Friendly: If the application is currently running, Installomator can prompt the user to safely quit the app.
  • Clean Delivery: Extracts applications and cleans up any downloaded archive files.
Customizable dialogs keep users informed.
